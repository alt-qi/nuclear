# Дополнительные специальные методы

Эти карточки полезны для отдельных трудных задач и не включены в короткую печатную часть.

## T19. Приближения с оценкой ошибки: ряд и проекции

**Ряд Тейлора в 2024 A.** Закон преломления сохраняет `C=r·sinθ`. При прохождении материала длины `l` и показателя `r` высота увеличивается на

$$
l\tan\theta=l\frac{C/r}{\sqrt{1-(C/r)^2}}
=l\sum_{k=0}^{\infty}\frac{\binom{2k}{k}}{4^k}(C/r)^{2k+1}.
$$

Из ограничений `C/r≤(16000/10000)sin30°=0.8`. Коэффициенты `a_k=binom(2k,k)/4^k≤1`, `a_{k+1}=a_k(2k+1)/(2k+2)`. После `K` членов хвост по модулю не больше `l·z^(2K+1)/(1−z²)` при `z=C/r`. Относительный хвост для положительной суммы не больше `0.64^K/0.36`; при `K=40` это меньше `5·10^-8`. Ошибку вещественных вычислений оценивать отдельно.

Поддерживать моменты `Σl_i(R0/r_i)^(2k+1)` с `R0=10000`, а в запросе умножать на `(C/R0)^(2k+1)`: так не возникают огромные и чрезвычайно малые степени. Отдельный Fenwick по длинам находит материал, содержащий стартовую координату; его неполный участок учесть отдельно. Изменение — `O(K log n)`, запрос — `O(K log n)`.

**Евклидова длина через проекции, 2021 I.** Для вектора `d`:

$$
\|d\|=\frac12\int_0^\pi|d\cdot(\cos\theta,\sin\theta)|\,d\theta.
$$

Взять `K` равноотстоящих направлений `θ_j=jπ/K`. Для каждого спроецировать точки, отсортировать `z_i` и найти сумму расстояний на прямой:

$$
\sum_{i<j}|z_i-z_j|=\sum_{i=0}^{n-1}(2i-n+1)z_i.
$$

Ответ — `π/(2K)` от суммы по направлениям. При `x=π/(2K)` отношение приближения к истинной длине любого ненулевого вектора лежит между `x cot x` и `x csc x`. При `K=20` границы примерно `0.997943` и `1.001029`; значит относительная ошибка всей суммы меньше 0.21%, что укладывается в 1%. Время `O(Kn log n)` без случайности. При совпадении всех точек ответ 0.

**Правило.** Допуск 1% — часть алгоритмических условий. Гарантированно случайный вход, как в 2024 L, тоже часть условий; вероятностное ограничение полосы DP нельзя объявлять доказанным для произвольного входа.

## T22. Определитель, теорема Кирхгофа и малый цикловой ранг

**Определитель по простому модулю.** Гаусс с ненулевыми ведущими элементами: перестановка строк меняет знак, произведение pivots даёт определитель; отсутствующий pivot означает 0. Деление — на обратный элемент. Стоимость `O(n³)`, поэтому сначала искать структуру матрицы.

**Кирхгоф.** У неориентированного графа лапласиан `L` имеет степени на диагонали и отрицательное число рёбер между вершинами вне диагонали. Любой главный минор размера `V−1` равен числу остовных деревьев. Кратные рёбра учитываются с кратностями. Для несвязного графа ответ 0.

**Сведение 2020 L.** Пусть столбец матрицы `B` — индикатор одного интервала. Тогда исходная матрица `A=BBᵀ`. Применить к строкам разностное преобразование `D` с определителем 1: индикатор `[l,r]` превратится в `e_l−e_{r+1}`, причём координата `n+1` удалена. Следовательно `DADᵀ` — минор лапласиана графа с вершинами `1…n+1` и ребром `(l,r+1)` на каждый интервал. Поэтому `det A` — число остовов этого графа.

**Почему ограничение `m≤n+300` помогает.** Выбрать остов `T`; вне него `k=m−n≤300` рёбер. Для связного графа его минор `L_T` имеет определитель 1. Если столбцы `C` задают дополнительные рёбра, лемма об определителе даёт

$$
\det(L_T+CC^T)=\det(I_k+C^T L_T^{-1}C).
$$

Элемент `b_(a,b)^T L_T^{-1} b_(c,d)` для единичных рёбер дерева равен

$$
\frac{dist(a,d)+dist(b,c)-dist(a,c)-dist(b,d)}2.
$$

Это скалярное произведение ориентированных путей; числитель всегда чётный. Матрица размера `k×k` строится через LCA, далее Гаусс за `O(k³)`. При `k=0` определитель пустой матрицы равен 1. Не нужно обращать огромную матрицу явно.

## T23. 2-SAT, at-most-one и Horn-SAT

В 2-SAT дизъюнкция `(a∨b)` даёт импликации `¬a→b`, `¬b→a`. Противоречие возникает, когда переменная и отрицание попали в одну SCC. Из порядка компонент восстанавливается присваивание; формула выбора true/false зависит от нумерации SCC конкретной реализации.

**At-most-one.** Для литералов `x1…xk` запрещены все пары истинных. Попарное построение даёт `Θ(k²)` ограничений, но последовательные вспомогательные переменные кодируют «среди первых i уже есть true» за `O(k)` клауз. Для повторяющихся или противоположных литералов учитывать исходную формулу, а не бездумно удалять дубликаты.

**Horn-клауза** содержит не больше одного положительного литерала. Её можно записать как `a1∧…∧ak→b` либо `a1∧…∧ak→false`. Начать с false для всех переменных; активные единичные выводы распространять очередью, уменьшая счётчик ещё не истинных предпосылок. Вывод false означает несовместность. Время линейно числу вхождений.

В 2020 J дано обещание существования набора переворотов, при котором в каждой строке не больше одной белой карты. Оно позволяет найти переименование переменных через at-most-one/2-SAT и сделать целевую формулу Horn. Затем решить её распространением. Сам исходный запрос «хотя бы одна белая» — не 2-SAT в общем случае; именно обещание из условия делает его специальным.

## T25. Конструкции: доказательство границы, раскраска и обмен

Сначала получить нижнюю/верхнюю границу ответа, затем построить объект, который её достигает. В 2022 C сторона 1 не может участвовать в невырожденном треугольнике с различными целыми сторонами; отсюда максимум не больше `floor((n−1)/3)`. Конструкция должна одновременно проверять `a+b>c` и `a²+b²<c²` при `a≤b<c`.

**Обменный аргумент.** Если в решении есть «плохая» пара, локально переставить элементы, не ухудшая целевую функцию. Так обосновываются группировка соседних цен в 2018 I и выравнивание длин чисел в 2024 G. После обмена нужно уменьшать строго определённую меру неправильности, чтобы процесс завершился.

**Пять цветов для планарного графа.** У планарного простого графа есть вершина степени не больше 5. Рекурсивно удалить её и раскрасить остаток. При пяти различных цветах соседей попробовать двухцветные компоненты Кемпе: если два нужных соседа лежат в разных компонентах, перестановка двух цветов в одной компоненте освобождает цвет. Планарность гарантирует подходящую пару. Слепой жадный алгоритм без перекрашивания гарантирует лишь 6 цветов.

**Из пяти цветов в 10 координат, 2025 H.** Для цвета `c` использовать только координаты `(2c−1,2c)`, в остальных поставить 0. Внутри одной цветовой пары выбрать различные целые точки `x²+y²=R`. Тогда вершины разных цветов находятся на одинаковом квадрате расстояния `2R`.

Подходит

$$
R=5^3\,13^2\,17^2\,29\,37\,41=268582764125<10^{12}.
$$

У него `4·(3+1)(2+1)(2+1)·2³=1152` упорядоченных целых точек на окружности. Координаты по модулю меньше `10^6`; их можно перечислить по `x` и точному целому квадратному корню. Здесь `R` — **квадрат радиуса**, а не радиус. Численная проверка перечислением дала 1152 точки. Этого хватает даже для одного цветового класса размера 1000.

## Короткий выбор метода на туре

| Признак условия | Что проверить первым |
|---|---|
| Несколько остатков / разные основания | КТО, НОК модулей, диапазон единственности |
| XOR по маршруту | Остовные потенциалы + базис циклов; разрешены ли повторы |
| Общий порог и много запросов | Монотонность, сортировка событий, parallel binary search |
| Каждому нужен разный объект | Паросочетание, Hall, цена объекта, отсечение кандидатов |
| Много переходов внутри группы | Общая вершина-посредник |
| Изменения поддерева | Euler tour и подходящий lazy-агрегат |
| Очень много мелких изменений | Потенциал, удвоение/деление пополам, суммарный бюджет |
| Счёт перестановок по циклам | Стирлинг, множители `(x+c)`, свёртки |
| Жёсткая память + нужен ответ | 2-битные предки или восстановление по середине |
| Точный вывод при вероятностях | Индикаторы, первый шаг, самопереход, целочисленный масштаб |
| Большой определитель из интервалов | Разности, incidence matrix, Кирхгоф, малый цикловой ранг |
| Огромный диапазон, малый алфавит | Частоты, остатки, конечный словарь, группировка |

## T21. Пакетные сравнения со стабильным равенством

**Пакетные сравнения с опорным элементом, 2025 I.** По условию минимум скрытого массива равен 0, а запрос не меняет сам массив. Сначала спросить нулевой массив и найти первый минимум `s`, значит `a_s=0`. Храним включительные границы `lo_i≤a_i≤hi_i`. До `s` положить `lo_i=1`, после — 0; `hi_i=C=10^9`. На раунде `mid_i=floor((lo_i+hi_i+1)/2)`, `b_s=C`,

$$
b_i=C-mid_i+[i<s],\qquad i\ne s.
$$

В стабильной сортировке индекс `i` окажется после `s` тогда и только тогда, когда `a_i≥mid_i`. Это одновременно обновляет все бинарные поиски. `mid_i≥1` для `i<s`, поэтому `b_i` остаётся в `[0,C]`. Нужно 1 начальный и не больше 30 поисковых запросов. Законченные позиции можно пропускать при обновлении границ. Формула не содержит дополнительного `−lo_i`: исходный массив между запросами не меняется.
