# Независимые проверки самостоятельных выводов

Сравниваем алгоритмы с другим способом решения малых экземпляров, а не
с копией той же формулы. Сторонний скачанный код не запускается. Нужна
только стандартная библиотека Python 3. Из этой директории:

```sh
python verify_derived.py
python verify_more.py
python verify_constructions.py
```

| Вывод | Независимая проверка |
|---|---|
| 2016 D | 15 000 случаев: наборы исходных позиций на всех этапах сноса |
| 2018 B | 600 графов: все метки рёбер −1/0/1 |
| 2018 J | 20 000 случаев: все назначения задач людям |
| 2018 K | 10 000 мультиграфов: все раскраски, включая петли |
| 2019 F | 252 случая: все наборы ворот |
| 2019 H | Все 64 правильные строки длины до 10: разбиения на любое число частей |
| 2020 F | 70 914 целей: полный граф законных срабатываний |
| 2020 M | 10 000 матриц из разрешённых преобразований |
| 2020 N | 4004 набора точек: все раскраски |
| 2021 C | Все перемешивания двух кратностей 1–3 и четыре примера |
| 2021 D | 137 249 кругов непустых мешков с тремя различными числами |
| 2021 E | Все анаграммы чисел до 300, минимумы перебором до 100 000 |

Это поиск ошибок в выводах, а не доказательство асимптотики и не получение AC.
Для 2023 A основное подтверждение — неравенство треугольника и уменьшение
числа различных позиций в доказательстве.
