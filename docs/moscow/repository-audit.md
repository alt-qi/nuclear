# Сопоставление с кодом команды

Первоначальная сверка сделана по `117ea4b`. Ниже учтены и новые заготовки
в ветке `trd/moscow-2016-2025`. Метка `RECHECK` обозначает старые шаблоны,
которые требуют отдельной проверки.

| Материал | Что уже есть | Что важно помнить при переносе |
|---|---|---|
| КТО и диофантовы уравнения | [Расширенный Евклид](../../include/algo/number_theory/extended_gcd.hpp), [КТО](../../include/algo/number_theory/crt.hpp) | Евклид возвращает НОД и коэффициенты Безу. КТО объединяет сравнения с произвольными положительными модулями и отдельно сообщает о несовместности и переполнении. |
| Компоненты связности | [DSU](../../include/algo/data_structures/dsu.hpp) | Обычное объединение компонент, их размер и проверка связности. Для XOR-ограничений понадобится хранить потенциалы, см. T04. |
| Простые и арифметические функции | Линейное решето, Miller–Rabin, bigint | Проверка простоты не выдаёт факторизацию; показатели в факториале и формулы делителей дополняются теорией. |
| Моноид и lazy | `segment_tree_recheck.hpp` | Реализованы add/max. Для multiply/sum нужны другие агрегат и композиция тегов. |
| Последовательности | Treap, явный и неявный splay | В treap есть sum/size. Нужные для конкретной задачи reverse, lazy, связи с родителем не появляются автоматически. |
| Расстояния по дереву | HLD и link-cut tree | HLD работает со статическим деревом. Центроидная декомпозиция и динамические перестройки отдельно не представлены. |
| Паросочетание и потоки | Кун, Диниц, min-cost max-flow | Главная добавленная часть — построение сети, вложенные ёмкости, обратные дуги, условия применимости. |
| Строки | KMP, Z, AC, SAM, suffix array/LCP, suffix tree | Не хватает отдельной карточки Манакера и дерева границ; теоретическое сведение не требует менять имеющийся код. |
| Геометрия | Точки/векторы, статический Грэхем | Динамическая оболочка, отсечение полуплоскостью и опорные запросы — другие операции. |
| XOR и графы | Теоретические справки | DSU с потенциалами, XOR-базис, SCC/2-SAT и топологическая DP описаны в T03–T05. |
| Вероятность и комбинаторика | Специальных заготовок не обнаружено | Индикаторы, условное ожидание, модульные дроби, fact/invfact стоит иметь в памяти и справочнике. |
| Свёртка | [Целочисленная свёртка через FFT](../../include/algo/number_theory/convolution_fft.hpp) | Результат округляется после обратной FFT. Ограничения заготовки и пример расчёта приведены в T15. |

## Что включено в печатную часть

После кода идут формальная теория с примерами и карточки распознавания
идей. Раньше в печатной части была черновая версия расширенного Евклида.
Её файл остался в библиотеке, а в оглавлении теперь новая заготовка.

Полная карта 124 задач, исходные PDF, источники, подробные самостоятельные
доказательства и специальные методы остаются в `docs/moscow`: они полезны
для подготовки, но не раздувают короткую печатную часть.
