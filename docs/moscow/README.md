# Теория и идеи для std::nuclear

В основе справочника десять московских контестов ICPC за **2016–2025 годы**,
всего 124 задачи. Материалы рассчитаны на команду уровня Codeforces 1600.

[Открыть собранный TRD — 27 страниц](preview.pdf).

## Читать в первую очередь

- В формальной теории каждая карточка начинается с вопроса, на который
  отвечает метод. У КТО, XOR-базиса и свёртки есть примеры с ручным расчётом.
  [Теория](../../include/notes/theory.md)
- У каждого приёма есть короткое условие и объяснение, как из него получить
  решение. [Идеи решения](../../include/notes/problem-solving.md)
- В таблице перечислены готовые реализации и границы их применения.
  [Сопоставление с кодом](repository-audit.md)

## Проверяемое покрытие

Все **124 условия** сохранены в [materials](materials).
Для **101 задачи из 124 (81,45%)** в [полной карте](contest-map.md) есть
прочитанный разбор/код либо самостоятельно восстановленный алгоритм.
**23 пробела** явно помечены `Н` и в покрытие не входят.

- `Р`: 38 задач с прочитанным текстовым разбором.
- `А`: 22 задачи с прочитанным командным конспектом или кодом.
- `В`: 41 самостоятельный вывод, без утверждения об AC.
- `Н`: 23 задачи без подтверждённого полного подхода.

Это покрытие **материалом для выделения теории**, а не 101 готовая реализация.
Некоторые опубликованные разборы коротки и оставляют оптимизацию читателю.
Самостоятельные выводы тоже не заменяют отправку в проверяющую систему.

## Сборка и изменения

Команда сборки `make typst`. Формальная теория и идеи подключены в конце
`trd.yaml`. В перечень кода добавлены DSU, расширенный Евклид, КТО и свёртка
целых чисел через FFT. Условия, полная карта задач и дополнительные разборы
доступны отдельно в `docs/moscow`.

## Что проверено

PDF собран Typst 0.15.1. Просмотрены оглавление, страницы с новым кодом
и семь страниц заметок. Евклид проверен на знаковых границах `long long`,
КТО сверена с перебором, DSU с простой моделью компонент, FFT с прямой
свёрткой и с контрольным примером на длине преобразования `2^20`.
При подготовке архива проверены 124 уникальные записи, распределение
статусов и 13 хешей исходных PDF.
