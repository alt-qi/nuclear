# Теория и идеи для std::nuclear

Десять последних завершённых московских контестов ICPC:
**2016–2025, 124 задачи**. Подготовлено 6 ноября 2026 года для команды уровня
Codeforces 1600. Знакомые методы объясняются через смысл, формулы и применение.

[Открыть собранный TRD — 29 страниц](preview.pdf).
Это предпросмотр данной ветки; действующий релиз основной ветки он не заменяет.

## Читать в первую очередь

- [Формальная теория](../../include/notes/theory.md): определения, формулы,
  обоснования и условия применения. Включена в PDF.
- [Идеи решения](../../include/notes/problem-solving.md): выбор модели, обмен,
  вклад элемента, исправление стыка и другие повторяющиеся приёмы.
  Включены в PDF отдельным разделом.
- [Сопоставление с кодом](repository-audit.md): что уже есть в библиотеке
  и каких вариантов структур требуют конкретные задачи.

## Проверяемое покрытие

Все **124 условия** сохранены в [materials](materials).
Для **101 задачи из 124 (81,45%)** в [полной карте](contest-map.md) есть
прочитанный разбор/код либо самостоятельно восстановленный алгоритм.
**23 пробела** явно помечены `Н` и в покрытие не входят.

- `Р`: 38 задач с прочитанным текстовым разбором.
- `А`: 22 задачи с прочитанным командным конспектом или кодом.
- `В`: 41 самостоятельный вывод, без утверждения об AC.
- `Н`: 23 задачи без подтверждённого полного подхода.

Это покрытие **материалом для выделения теории**, а не 101 готовая реализация.
Некоторые опубликованные разборы коротки и оставляют оптимизацию читателю.
Самостоятельные выводы тоже не заменяют отправку в проверяющую систему.

## Сборка и изменения

Обычная команда репозитория: `make typst`. Два Markdown-файла подключены
в конце `trd.yaml`; используется поддержка Markdown из коммита `117ea4b`.
В рендере заметок увеличен размер встроенных кодовых выражений и убрана
лишняя вложенная нумерация заголовков. Форматирование исходного C++ и сами
алгоритмические файлы команды не менялись.
Полная карта и дополнительные материалы в печатную часть не включены.

Работа опубликована в ветке `trd/moscow-2016-2025`. Основная ветка и текущая
PDF-публикация GitHub Releases этой работой не обновляются. После просмотра
можно перенести ветку обычным слиянием и запустить стандартную публикацию.
