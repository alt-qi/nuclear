# Московские контесты 2016–2025: подготовка теории

Рабочие материалы для TRD команды `std::nuclear`. Работа продолжается.

## Задача

Разобрать десять последних завершённых московских контестов из
[категории QOJ](https://qoj.ac/category/280): 2016–2025, всего 124 задачи.
Собрать условия и решения минимум для 100 задач (не менее 80%), затем выделить:

- понятные теоретические справки с условиями применимости, формулами и примерами;
- повторно используемые идеи решений, которые не сводятся к названию алгоритма;
- сопоставление с уже имеющимся кодом команды.

Уровень объяснений: знакомство с основными алгоритмами, примерно Codeforces 1600.
Сложные специальные методы не должны вытеснять полезную базовую теорию.

## Текущее состояние

Все десять комплектов условий скачаны и извлечены в текст в локальной папке
`research` рядом с репозиторием. Условия содержат 124 задачи.

Прочитаны текстовые разборы контестов
[2022](https://relia.uk/download.php?id=1329&r=1&type=attachments),
[2024](https://relia.uk/download.php?id=2620&r=1&type=attachments) и
[2025](https://relia.uk/download.php?id=4614&r=1&type=attachments): 38 задач.
Дополнительно прочитаны отдельные командные разборы и реализации 2016, 2017 и
2020 годов. Остальные записи пока включают самостоятельные выводы и пробелы.
Полное покрытие решениями ещё не достигнуто.

В итоговом реестре каждая запись будет различать прочитанный разбор,
прочитанный код, самостоятельное доказанное решение и неподтверждённое направление.
Неподтверждённые направления не входят в показатель покрытия.

## Работа с репозиторием

Материалы готовятся в отдельной ветке `trd/moscow-2016-2025` от коммита
`117ea4b` с поддержкой Markdown. Основная ветка, алгоритмы команды и действующая
публикация PDF этим рабочим коммитом не изменяются. Подключение готовых заметок
будет проверено сборкой PDF до публикации результата.
